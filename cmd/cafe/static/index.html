The shape of it

Four steps, and the fourth is optional

There is no sign-up, because there is nothing to sign up for: the key you connect with is already a Solana account, and that account is the balance.

01

Connect

An ed25519 key is a Solana account, so the key that authenticates your SSH session names the account the money belongs to. No email, no password, no onboarding. 

ssh -A router.cafe
02

Deposit

Press d, type an amount. The server asks your own agent, reached through the ssh -A you forwarded, for a signature on a transfer. Your key never crosses the connection.

The transaction that comes back is checked against what was asked for before it is broadcast: one System transfer, two accounts, the amount you typed.

03

Mint a key

Press k. A rc_… key is shown once, and only its fingerprint is kept, so the server's own ledger is not a file of live credentials.

04

Point a client at it

Anything that speaks the OpenAI API works. Swap the base URL and the key, and the model names are RouterCafe's, so they do not change when a provider does. 

export OPENAI_BASE_URL=https://api.router.cafe/v1
export OPENAI_API_KEY=rc_a7c4...3f9a

The part that is different

There is no shell. Not hidden, not disabled, not behind a flag.

Every public SSH service eventually grows a command that runs something. This one never does, and the reason is structural rather than a promise: the session is a program, so there is no path from a connection to a process.

ssh router.cafe uptime refused, exit 1
ssh -s router.cafe sftp subsystem refused
ssh -L 8080:127.0.0.1:8080 router.cafe no channel
ssh -D 1080 router.cafe no channel
ssh -A router.cafe the session UI

The only four things a connection can reach: the UI, the ledger, the API, and a signature request to the agent you forwarded.

✓

Your key stays yours

A deposit is an ordinary signature request to the ssh-agent your client forwarded. The private key is never sent, and the server never holds one.

✓

The transaction is read back before it is sent

The signed bytes are decoded and checked: one System Program transfer, the fee payer is the account paying, no writable account other than the source and the treasury, and the amount is the amount you typed. Anything else is refused and nothing is broadcast.

✓

Balances are integers

Credit is counted in millionths of a dollar in an int64, and a request reserves the most it could cost before it starts and is refunded the difference afterwards. A balance cannot go negative and there is no rounding rule anywhere near the decision.

✓

The ledger is not a credential file

API keys are stored as SHA-256 digests. A copy of the ledger gives an attacker balances and fingerprints, not keys.

Questions people actually ask

Before you connect

Why not just use OpenRouter?

You may well. RouterCafe is the same shape with two differences: you pay in SOL from the terminal, and the front end is a terminal session rather than a dashboard. If you want a web console and a card, they are the better product.

What does a deposit cost?

The Solana network fee, which is a few thousand lamports, taken out of the amount you send. Deposits below roughly 0.00001 SOL are refused rather than spent entirely on the fee, and the TUI says so before you sign anything.

Why does it need ssh -A?

Because that is how it asks your key to sign. Without agent forwarding there is no way for the server to reach a key that is on your machine, and it would have to ask you to hand it over, which is exactly the thing it should not do. The deposit screen tells you this rather than failing silently.

Can I use a wallet instead of an SSH key?

Yes. The browser terminal at /app signs in with a Solana wallet and shows the transaction for you to approve before it is sent, which is the same flow through a different key holder.

What happens to my key if it leaks?

Press k and revoke it, then mint another. The balance belongs to the account rather than to the key, so revoking does not touch your credit.

Is the rate fixed?

The SOL price is set by whoever runs this instance and recorded on every deposit, so what you were credited at is not something that can change afterwards. It is shown on the deposit screen before you sign.

Can I self-host it?

Yes. It is one binary and one flag: cafe --treasury <address> --upstream <url> --upstream-key <key>. The ledger is a JSON file; back it up or do not.
